## 🏗️ ArtDepartmentAgent Specifications

### Input
- The script excerpt is capped at `limits.script_art_department` characters (default 20 000); longer scripts are truncated with a warning.

### Extraction strategy
1. **Characters** — the 3-5 who drive the scene (dialogue or plot-moving action). Skip one-line extras.
2. **Locations** — 2-4 recurring or narratively significant places (e.g. "place of power", "confrontation space").
3. **Props** — 2-4 story-critical objects (weapons, documents, symbolic items); ignore generic set dressing.
4. **Narrative context** — `time_period`, `global_mood`, `key_events`, `cultural_context`.
5. **Project settings** (Showrunner) — location lock, era lock, negative constraints, style overrides; the script is the only source of truth, overriding training-data associations.

### Field rules
- `CharacterAsset`: `id`, `name`, `description`, `personality` required; `voice_preset_id` may be null.
- `LocationAsset`: `id`, `name`, `type` (INT / EXT / UNKNOWN), `visual_style` required.
- `PropAsset`: `id`, `name`, `visual_description`, `importance` ∈ critical / supporting / background.
- Descriptions are visual identifiers (scars, wardrobe, build) that keep the character recognisable across shots — concise, no prose.

### Reference images
- Character sheets are generated by `CharacterPromptAgent` + `T2IClient` (or supplied under `character_list/`) and linked into `visual_references.canonical_image_path`. They are attached to every keyframe render of that character (TI2I, "Picture N").

## 🎤 VODirectorAgent Specifications

### Dialogue extraction (dialogue_extraction.yaml)
Given one shot (narrative action, emotional beat, entities, staging) and the script segment:
- Decide SILENT vs. speaking first. Pure action / reaction ⇒ `speaker_id = "silent"`, empty `full_dialogue`.
- Otherwise extract only the line(s) spoken at this moment, verbatim, same language as the script.
- `speaker_id` / `listener_id` come from the character ID mapping. Special listeners: `audience` (monologue), `group` (3+), `multiple` (2+ specific).
- Several speakers ⇒ `is_multi_speaker = true` and one entry per line in `dialogue_lines` (`speaker_id`, `listener_id`, `text`, `order`).

### Performance emotion (emotion_inference.yaml / emotion_visual.yaml)
- Shots with dialogue: infer from the line + the speaker's `personality` / `current_motivation` + staging (lighting, scale, movement) + the last 3 beats.
- Silent shots: infer the atmosphere from visuals alone (tag library: joyful, tense, melancholic, ominous, peaceful, chaotic, intimate, isolated, triumphant, neutral).
- Output a descriptive cinematic label + intensity 1-10; transitions between consecutive shots must be believable.
- Written to `narrative_layer.performance_emotion` / `performance_intensity`.

## 🎬 ProductionOperatorAgent Specifications

### Job assembly (no LLM)
- One `VideoJob` per shot from `render_layer.video.resolved_i2v`; dialogue shots are split into `prelude` / `dialogue_core` / `afterglow` segments whose durations sum to `duration_seconds` (each ≥ 1 s; a shot the line nearly fills stays whole).
- `frame_num` = duration × fps rounded to `4n+1`; `image_reference` = the shot's keyframe if rendered, else the first character's reference sheet.
- `assembly_layer` records transitions and the audio tracks (dialogue via the speaker's voice preset, BGM) the post stage lays down.

### Execution (opt-in, `execute: true`)
- Keyframe: TI2I with reference sheets (`resolved_ti2i`) or T2I (`resolved_t2i`) → `VisualJudge` → retry with the judge's revised prompt.
- Clip: I2V from the keyframe → sample frames → `VisualJudge` → retry.
- Post: clips cut together in shot order with ffmpeg (fade-in on the first shot) → `final_film_path`.
- Verdicts and final prompts are written back into the blueprint (`visual_review`, `keyframe_image_path`, `video_clip_paths`).
